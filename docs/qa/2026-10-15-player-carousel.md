# Плеер и карусель документов — локальная проверка

Дата: 15 октября 2026. Ветка `codex/responsive-typography`, после `eb53bda`.
Проверяется локальная папка `dist`, без публикации.

## Изменения

- Согласованы «Для знакомства», Цзин-ло и оформление плеера. «Цигун» проверено по словарю «Грамоты»; в тексте строчная буква.
- Четыре документа в ручной карусели с исходными фотографиями, счётчиком, кнопками и стрелками клавиатуры. Отзывы используют отдельную карусель.
- «Работа руками» — первый ролик. Под «Смотреть» тёмная подложка; видимых подписей длительности нет.
- Собственные кнопки запуска, паузы и звука, перемотка, загрузка, ошибка и повторная попытка. Нативные controls сохранены в HTML как резерв без JavaScript.
- Пункты 01–03 занимают всю ширину блока: строка, если помещаются все три, иначе одна колонка.

## Проверки основного исполнителя до независимого прогона

Проверены запуск, пауза с клавиатуры, выключение звука и остановка предыдущего ролика. Проверены окончание и повторный запуск. Карусель документов переключалась 1→2→3→4 и обратно кнопками и клавиатурой; крайняя кнопка отключалась. Карусель отзывов проверена отдельно.

При проверке перемотки обнаружено ограничение Python SimpleHTTPServer: браузер показывал seekable 0..0, хотя файл загружен. Локальный сервер заменён временным сервером с HTTP Range (206); после этого проверены End/Home и переход к концу. Этот вспомогательный сервер не является частью сайта и не меняет Vercel.

Независимое ревью кода указало на ошибку дочернего source: video.play() может оставаться незавершённым без video.error. На временной странице с отсутствующим MP4 воспроизведён вечный спиннер. Добавлены обработка error у source и load() при повторной попытке. Повторная проверка: ошибка видна, спиннер скрыт; после восстановления файла кнопка «Повторить» запускает видео. Отдельно проверен резерв без video-player.js: нативные controls остаются видимыми. Все временные страницы и MP4 удалены.

Свежие проверки после последних изменений: node --check dist/app.js, node --check dist/video-player.js, git diff --check — exit 0.
