# Наталья Кузнецова — массаж и телесные практики

Тёплый профессиональный сайт личной практики Натальи в Москве.
HTML, CSS и JavaScript без фреймворка, установки зависимостей и сборки.
`dist` — готовая папка для размещения, а не результат компиляции.

## Структура

- `dist/` — актуальный сайт, локальные шрифты, фотографии, документы и четыре оптимизированных MP4.
- `frontend/` — прежняя версия из истории этого репозитория; оставлена без изменений.
- `CONTENT-NOTES.md` — происхождение сведений и редакционные ограничения.
- `TODO.md` — подтверждённые замечания и предложения следующего этапа.
- `reviews/` — независимые маркетинговое и UX-ревью от 15 октября 2026 года.

Исходные MOV, запись экрана Telegram и скриншоты отзывов не включены.
Ревью содержат снимки сайта; ограничения fullpage-экспорта описаны в отчётах.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:4178/`.
Проверка синтаксиса: `node --check dist/app.js`.

## Vercel

Конфигурация в `vercel.json`:

- Root Directory: корень репозитория (`./`).
- Framework Preset: `Other`.
- Build Command и Install Command: пустые.
- Output Directory: `dist`.

Если существующий проект Vercel использует Root Directory `frontend`, перед публикацией
её нужно переключить на корень. Настройки существующего проекта Vercel ещё не проверены.
Автоматические Git-деплои ветки `codex/natalia-site` отключены; для остальных веток эта
конфигурация не меняет стандартное поведение. Публикация требует отдельного разрешения
пользователя. Конфигурация не блокирует ручную публикацию через интерфейс или CLI.

Документация: [статические сайты](https://vercel.com/docs/builds),
[управление Git-деплоями](https://vercel.com/docs/project-configuration/git-configuration).

## Текущее поведение

Кнопки записи показывают форматы и открывают профиль Натальи в Telegram или звонок.
Сайт не отправляет сообщения и не бронирует время; запись согласуется лично.
Личного кабинета, серверной части, базы данных и календаря пока нет.
Индексация отключена (`noindex,nofollow`) до согласованного запуска.

Диагностический сеанс — 5 700 ₽ вместо 7 800 ₽, базово 55 минут;
массаж тела — 5 700–7 800 ₽; абонемент — скидка 15%.
Продлённые сеансы и обучение согласуются отдельно.
В тексте названы классический, спортивный, лимфодренажный и комбинированный массаж.
Рекомендации ревью, кроме этого уточнения названий, ещё не реализованы.

## Медиа и лицензии

Фотографии, документы, видео и отзывы предоставлены пользователем для сайта.
Веб-видео: MP4, 720×1280, H.264/AAC, faststart, оригинальный звук, без автозапуска,
`preload="none"`. Исходные MOV не изменены. Источник фото и ограничения — в `CONTENT-NOTES.md`.
Шрифты Cormorant Garamond и Manrope размещены локально с лицензиями OFL в `dist/assets/`.

`dist/assets/hero.png` — прежняя концептуальная иллюстрация ImageGen, на странице не используется.
Она не изображает реальный кабинет. Промпт генерации сохранён в `DESIGN-PROVENANCE.md`.
Код репозитория распространяется по существующей MIT-лицензии в `LICENSE`;
вопросы использования предоставленных медиа отдельно от сайта согласуются с правообладателями.
