публикация требует отдельного разрешения пользователя. Индексация также пока отключена.
Отключение применяется, когда Vercel читает этот `vercel.json` из корня проекта;
настройки уже подключённого проекта Vercel пока не проверены.
Документация: [статические сайты и сборка](https://vercel.com/docs/builds),
[управление Git-деплоями](https://vercel.com/docs/project-configuration/git-configuration).
