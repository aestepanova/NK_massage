# Мобильная плотность и равные поля

16 октября 2026 года. Пользователь попросил немного сократить вертикальные отступы и повторы, сохранив премиальный стиль; отдельно назвал равные боковые поля критичным требованием. Результат внедрён в локальный dist без публикации, push или PR/MR.

## Причина смещения и решение

На CSS-ширине 390 px все основные .wrap и вложенные полные колонки уже имели поля 20/20 px относительно области содержимого (clientWidth=375). Однако были два отдельных дефекта:

1. Шапка: меню заканчивалось на x=370.41, хотя правая граница общей колонки x=355. Сумма минимальных размеров имени, кнопки, меню и промежутков превышала ширину. На mobile уменьшены промежутки шапки до 8 px, имя бренда до 18 px, внутренние поля/промежуток компактной кнопки до 6 px; меню сохраняет ширину. Теперь его правая граница совпадает с колонкой. Дополнительно проверена граница 371 px: x=336 у колонки и меню. Прежнее скрытие кнопки до 370 px сохранено.
2. Полный снимок: браузер при захвате убирал вертикальную полосу прокрутки, расширял вёрстку на 15 px, но сохранял изображение шириной 375 px. В прежнем полном снимке рамка прайса имела границы x=20..369: слева 20, справа 5 px. Отдельная проба только html{scrollbar-gutter:stable}, до сокращения текста, дала x=20..354 — 20/20 px. Стабильное место под полосу также сохраняет ширину при открытии диалога. В финальном полном снимке поля вновь 20/20; [пиксельная сверка](evidence/2026-10-16-mobile-compact/screenshot-margins.json). Неподдерживающий scrollbar-gutter браузер сохраняет прежние симметричные .wrap; реальные телефоны отдельно не проверялись.

Текст внутри колонок остаётся выровненным влево. Выровнены границы блоков, а не центрированы все абзацы.

## Сокращения

Удалены отдельный переход «Начнём со знакомства» после hero, три кратких принципа подхода и повторный вводный абзац первого визита. Эти сведения уже раскрыты в прайсе и трёх шагах. Девиз дословно перенесён в конец раздела о подходе. Шаги первого визита и пояснение немедицинского смысла диагностики в FAQ сохранены.

На mobile вертикальные поля основных разделов сокращены с 56 до 40 px; меньше промежутки в прайсе, строках практик/шагов, FAQ и контактах. Основной текст, H1/H2/H3 и их межстрочные интервалы не уменьшались. Рамки, тени, палитра, два семейства, источники медиа и знак бренда сохранены. На 390 px длина уменьшилась с 10 521 до примерно 9 650 px — около 8%. Разница в несколько пикселей между снимком (9 647) и повторным DOM-измерением связана с состоянием отрисовки; процент округлён.

## Проверки

```text
git status --short
python3 scripts/check_site.py
python3 scripts/check_site.py --root sites/natalia-kuznetsova
git diff --check
git diff --no-index -- <before-index.html.txt> <dist/index.html>
git diff --no-index -- <before-assets-sections.css.txt> <dist/assets/sections.css>
```

Обе статические команды — PASS (1/2 HTML); локальные ссылки, CSS URL и синтаксис JS корректны. git diff --check без ошибок; no-index показывает только описанные изменения (код 1 означает наличие diff).

Основной агент проверил локальный http://127.0.0.1:4188/dist/ в настольном IAB. [Браузерные измерения](evidence/2026-10-16-mobile-compact/browser-checks.json), [финальная геометрия 390](evidence/2026-10-16-mobile-compact/final-390.json).

| CSS-ширина | Поля основных контейнеров | Горизонтальное переполнение |
| --- | --- | --- |
| 320 | 16/16 px | нет |
| 371 | 20/20 px | нет; меню в границах |
| 390 | 20/20 px | нет; меню в границах |
| 768 | 24/24 px | нет |
| 1440 | равные, с учётом max-width 1240 | нет |

Во время проверки временно изменился масштаб браузера. Проверки геометрии учитывают фактический innerWidth, а не только запрошенный размер окна; фокус повторно проверен при подтверждённых 320×568. Финальный снимок сделан при innerWidth=390/clientWidth=375.

Целевые UI-сценарии:

1. На 320 px меню открывается, «Стоимость» ведёт к #prices и закрывает меню. Первый сеанс показывает 55 минут и 5 700 ₽ вместо 7 800 ₽; Escape закрывает диалог и возвращает фокус. На дополнительной фактической ширине 291 px длинный вариант обучения выбирается без горизонтального переполнения диалога.
2. На 320×568 Tab из контактной кнопки проходит через Telegram к телефону; полный контур телефона виден (top=370.51/bottom=400.31). [Снимок фокуса](evidence/2026-10-16-mobile-compact/phone-focus-320.jpg). Светлый фокус проверен на ссылке «Обсудить длительность».
3. Вопрос о длительности открыт/закрыт, карусель переключена с 1 на 2 кнопкой Next при фактической ширине 429 px. Их JS не менялся. Полный повтор всех девяти форматов и воспроизведения четырёх видео не выполнялся: они проверены в предыдущем цикле, атрибуты и сценарии сохранены независимо по исходникам.
4. Просмотрены шапка и прайс mobile, первый визит mobile/desktop, подход 768 и полный финальный снимок 390. Документы загружены. Журнал браузера без ошибок/предупреждений.

Реальные телефоны, touch selection и системный reduced motion в этом цикле не проверялись. Их открытый пункт TODO сохранён. Сообщения, звонки, заявки и внешние публикации не отправлялись. Вкладка и сервер оставлены для просмотра.
