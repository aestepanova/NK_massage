# Первый цикл: читаемое выделение текста

15 октября 2026 года. Режим — одна небольшая локальная доработка с независимым QA.
Результат: исправление проверено. Публикация, push и PR/MR не выполнялись.

## Выбор и воспроизведение

Взят существующий подтверждённый пункт TODO о читаемости выделения. Он требует
одного CSS-свойства, не затрагивает содержание и не зависит от внешних данных.
Маркетинговое и конкурентное исследование для этой задачи не требовалось.

Оркестратор воспроизвёл проблему в Codex In-app Browser: при двойном щелчке
по контактному заголовку слово «одного» почти исчезало. Для `#contact-title em`
вычисленный цвет выделенных букв — `rgb(213, 221, 191)`, фон —
`rgb(215, 221, 197)`. В `::selection` был указан только фон.

Источники: актуальные TODO, styles.css и UX-ревью от 15 октября. Новое
воспроизведение и снимки сделаны в этом цикле; прежнее ревью не заменяло проверку.

## Участники и изменение

Оркестратор выбрал задачу, сохранил исходные метрики/снимки и хеши 27 файлов,
проверил diff и доказательства, обновил документацию.
`selection_builder` запущен как `site_builder`, владел только dist/styles.css.
`selection_independent_qa` запущен как `site_qa`, самостоятельно проверил файл,
статическую команду и интерфейс. Его запись ограничивалась каталогом доказательств.
Именованные типы ролей приняты инструментом запуска в этом цикле.

Единственное изменение файлов интерфейса:

```diff
-::selection{background:#d7ddc5}
+::selection{background:#d7ddc5;color:#203c32}
```

Байтовое сравнение подтвердило ровно эту замену. Остальные 26 файлов dist
совпадают с исходными. Расчёт отношения относительных яркостей для проблемной
пары цветов: **1,01:1 → 8,57:1**. Это расчёт цветов, а не полный аудит доступности.

## Независимая проверка

Браузер: Codex In-app Browser через CUA; свежий локальный origin
`http://localhost:4173/`. Зафиксированы реальные `innerWidth` 320, 390, 768 и
1440 px при высоте 960 px; размеры не выводились только из команды viewport.

| Критерий | Результат и доказательство |
| --- | --- |
| Цвет выделения | PASS на всех четырёх ширинах: 9 элементов/типов текста, включая H1, зелёный и светлый текст, телефон, ссылку и кнопку; везде буквы `rgb(32,60,50)`, фон `rgb(215,221,197)` |
| Фактическое выделение | PASS: контактный заголовок и обычный текст проверены визуально; снимки `after-*.jpg` и `after-ordinary-*.jpg` |
| Горизонтальное переполнение | PASS: scrollWidth равен clientWidth — 305, 375, 753 и 1425 px соответственно |
| Окно записи и Escape | PASS на 390 и 1440 px: первый сеанс, 55 минут, 5 700 ₽ вместо 7 800 ₽; Escape закрывает диалог и возвращает фокус исходной кнопке |
| Мобильное меню | PASS на 320 и 390 px: открывается, закрывается кнопкой; на 390 px также закрывается после перехода по ссылке |
| Статическая проверка | PASS: `python3 -B scripts/check_site.py`, exit 0 — 1 HTML, локальные ссылки/CSS URL и 1 JS |
| Объём diff | PASS: изменён только styles.css; HTML, JS и ресурсы совпадают по хешам |
| Логи страницы | Список ошибок/предупреждений, полученный QA через dev.logs, пуст |

Размеры H1 и контактного заголовка сопоставлены с исходными. Точное равенство
геометрии не заявляется: исходная вкладка
была при масштабе 110%, вкладка QA — 100%, ширина полосы прокрутки различалась
на 1 CSS px. Сам diff не содержит изменений размеров или межстрочных интервалов.

Основной агент повторно выполнил статическую проверку и байтовое сравнение,
прочитал структурированные результаты QA и просмотрел снимки 1440/390 px.

## Доказательства и ограничения

- [До, 1440 px](evidence/2026-10-15-selection/before-1440.jpg) и [после, 1440 px](evidence/2026-10-15-selection/after-1440.jpg).
- [После, 390 px](evidence/2026-10-15-selection/after-390.jpg) и [обычный текст, 390 px](evidence/2026-10-15-selection/after-ordinary-390.jpg).
- [Исходные метрики](evidence/2026-10-15-selection/before.json), [независимый браузерный QA](evidence/2026-10-15-selection/independent-qa.json) и [статическая сверка QA](evidence/2026-10-15-selection/independent-static.json).

Исходный origin `127.0.0.1` сохранял старый CSS в кэше даже после обычной
перезагрузки. В логе сервера не было повторного запроса CSS. Новый origin
`localhost` загрузил актуальное правило; DOM не менялся и тестовый CSS не внедрялся.
Внешние диагностические ошибки Statsig инструмента CUA не приписывались сайту.

Это проверка настольного браузера на разных ширинах, без реального телефона.
Нативные кнопки проверены по вычисленным стилям; их текст может не выделяться
стандартным жестом браузера. FAQ, видео и карусель не проходились повторно:
для этой цветовой правки их HTML/JS подтверждены неизменными. Эмуляция
reduced motion не запускалась, соответствующие правила CSS не менялись.

Известные обрезание букв H1 при выделении и слабый фокус в тёмном блоке
остаются отдельными пунктами TODO; этот цикл не заявляет их исправление.
Следующий кандидат — воспроизвести обрезание крупных заголовков и отдельно
проверить минимальную корректировку межстрочного интервала.
