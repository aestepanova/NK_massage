# Макет первого экрана с портретом

Пользователь подтвердил направление 16 октября 2026 года. Это отдельный локальный макет для выбора композиции перед внедрением в активный сайт.

Открыть `index.html` через локальный сервер, запущенный из папки сайта:

```sh
python3 -m http.server 4188 --bind 127.0.0.1 --directory sites/natalia-kuznetsova
```

Адрес: `http://127.0.0.1:4188/reviews/concepts/2026-10-16-premium-hero/`.
В верхней строке есть ссылка на текущую версию для сравнения.

В макете изменены первый экран и короткий переход к знакомству. Остальная страница скопирована из версии `dist/index.html` на этапе создания концепта и явно отделена пояснением. Это позволяет проверить существующие меню и окно записи без создания нового сценария. Стили, скрипт, фотографии и шрифты берутся из локального `dist/`.

Новые элементы композиции: прямоугольный портрет Натальи, двухстрочный заголовок на широком экране, заметные цена и длительность, подтверждённая география. На телефоне цена и кнопка предшествуют портрету, длинное объяснение идёт после него. Знак бренда, два семейства и межстрочный интервал H1 1.2 сохранены.

Это макет первого экрана, а не законченный редизайн всей страницы. Повторный портрет и прежние секции ниже пояснения относятся к исходному оформлению.

в этом концепте тоже уточнены рамка фотографии и стрелки записи. [Текущее состояние и проверки](../../agent-cycle-2026-10-16-hero-transfer.md). Новая съёмка, публикация и реклама не выполнялись.
